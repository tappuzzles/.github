# TapPuzzles

Browser-based sorting, jam, and logic puzzles plus free open-source client-side puzzle solvers at **[tappuzzles.com](https://tappuzzles.com)**.

## Interactive Web Tools

- **[Water Sort Solver](https://tappuzzles.com/water-sort-solver)** — Weighted A* solver supporting 3–14 tubes, +1 extra empty tube deadlock checks, and hidden (`?`) layer reveal hints.
- **[Ball Sort Solver](https://tappuzzles.com/ball-sort-solver)** — Single-ball move rules for 3D sphere tube puzzles.
- **[Nut & Bolt Sort Solver](https://tappuzzles.com/nut-sort-solver)** — Color-stacking nut & bolt calculator.
- **[Daily Water Sort](https://tappuzzles.com/daily-sort)** & **[Daily Ball Sort](https://tappuzzles.com/daily-ball-sort)** — Deterministic UTC daily seeds verified solvable with par scores.

## Mobile Event Solvers
